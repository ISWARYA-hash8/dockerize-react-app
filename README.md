Here I , dockerized my react App by using Docker commands and learned about volumes also the basic image and containers 


-----------------------------
A Docker image is like a blueprint for a container.

It contains your code, dependencies, runtime, and system tools.

You can think of it like a snapshot of an app and its environment.
------------------------------------------------------------------

A container is a running instance of a Docker image.

It’s lightweight and isolated.

Runs the application just like on a real system, but without needing a full OS.
